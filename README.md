# ABHI FIRE ROYAL

Offline single-player battle royale prototype built with Godot 4.

## Included
- Procedural 3D arena and cover
- First-person player movement and aiming
- 12 chasing enemy bots
- Raycast shooting, ammo and reload
- Shrinking safe zone, health, kill counter, elimination and Booyah states

## Desktop test controls
- WASD: move
- Mouse: aim
- Left click: shoot
- R: reload
- Esc: release mouse

GitHub Actions workflow builds an Android APK on every push to main and can also be started manually. Download the APK from the workflow run Artifacts section.

This is an original offline prototype and is not affiliated with Garena Free Fire.
